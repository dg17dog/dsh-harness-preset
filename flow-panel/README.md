# dsh-harness-flow（驾驭工程流程面板）

> **可选组件（2026-10-01 起）**：驾驭工程 preset v2.0 已是**纯提示词工程**——不装本插件也能完整运行
> （官方桌面端 / 任何无插件环境照常）。本插件只提供 web 端的**观测与同步面**：状态可视化、每轮注入、
> 阶段同步；**不拦截任何工具调用**（G1–G5 门禁已于 v0.15.0 取消，仅保留非 harness 会话的预设门禁）。

「驾驭工程模式」（preset `harness`）的配套 UI 插件：会话顶栏「驾驭工程」入口 → 浮层面板，
显示**项目总目标 / 当前对话目标 / 十节点循环流程图（可自选线路）**，模型经 `harness_flow`
工具同步阶段推进，用户点节点或回路 = 自选线路。

## 形态

| 文件 | 是什么 |
|---|---|
| `lib/index.js` | Host 半：会话级流程状态（落盘 `~/.dsh/harness-flow/<sessionId>.json`）+ loopback HTTP 通道（GET/POST `/api/harness-flow/state`）+ 模型工具 `harness_flow`（raw JSON-Schema 形态注册，零 npm 依赖） |
| `lib/client.js` | Client 半（`__ModuleLoader__` bundle，零构建）：顶栏芯片 + 浮层面板；按 `projectionValues.agentPreset.id === "harness"` 门禁渲染，其他模式零渲染 |
| `package.json` | `dsh.client.platform: web`；无 bundle 声明（走 profile 用户层 patch 手动挂载） |

## 代理树面板（2026-09-19 三次改版，最终形态）

- **UI**：顶栏「驾驭工程」按钮**下方拉出的小窗**（fixed 按 getBoundingClientRect 锚定；不能用 absolute——conversation 根在 active 相位 overflow:hidden 会裁掉），点外部关闭。
- **工作路径选择器（核心）**：用户点选让模型走哪条路，属**预先放行**——
  完整流程（默认）/ 主代理直接工作（跳过三层编排与立项关卡）/ 立项不攻击 / 免审全自动（等同自主模式声明）/ 探索模式。
  被跳过的关卡在流程图上灰化 +「跳过/自动放行」徽标；路径切换后当前节点自动迁移到最近未跳过节点并留痕；
  跳过的关卡代理不得自行恢复，交付时按流程偏差申报注明所用路径（directive 经 harness_flow 返回给模型）。
- **十节点主线**：意图理解 → 目标探索（模糊才走）→ 判型 → 立项条款 → 攻击/审计（按需）→ 用户放行·冻结 → 发卡执行 → 内容验收 → 高风险审计（按需）→ 交付·自证。
- **运行期回路**：驳回修订回路 / 打回重做回路 / 走高风险审计 / 验收通过→交付 / 新需求→重新判型。

## 代码兼容（与子代理分发体系）

- 工具注册用 `ctx.tools.register` raw 形态，不改 standard 工具面任何行；`subagent` / `subagent_fork` /
  `goal` / `todo_write` 照常可用，面板只是状态同步面，不拦截、不改写任何调度。
- Client 半注册进 `conversation.session.header.utilities`（list 协议，追加不替换），不触碰现有顶栏控件。
- 门禁 fail-closed：sessions store 不可用或 preset 非 `harness` 时渲染 null。
- 状态通道 loopback 栅栏（socket + Host 头 + same-origin，与 dsh-usage 同口径）。

## 安装（本机已执行）

1. profile 依赖：`profiles/web/package.json` 增 `"dsh-harness-flow": "link:D:/驾驭工程性能测试/dsh-preset/flow-panel"`；
2. 链接：`node_modules\dsh-harness-flow` junction → 源码目录；
3. 挂载：`profiles/web/cordis.patch.yml` 追加 `- insert: - id: harness-flow-panel, name: dsh-harness-flow`；
4. **重启 dsh web 生效**（bundle/patch 层在 host 启动时装载）。

卸载：删上述三处 + 删除 `~/.dsh/harness-flow/` 状态目录（可选）。
